# Add-ons

Snap Gallery includes an editor button plugin and supports optional add-ons for extended functionality.

- **[Editor button](editor-button-add-on.md)** — Insert gallery tags from the editor toolbar (included with Snap Gallery)
- **[Layouts add-on](layouts-add-on.md)** — Additional gallery layout options
- **[Module add-on](module-add-on.md)** — Display galleries in Joomla modules
- **[Social add-on](social-add-on.md)** — Social media sharing integration
